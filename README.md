# 数据结构课程设计（T1 ~ T10）

本仓库截至最近一次提交完成至T2


本仓库是《数据结构课程设计》的完整作业工程：按 `数据结构课程设计题目.docx` 的要求，一题一个文件夹，每题目包含**头文件、主函数源文件、可执行文件（需自行编译）、项目说明文档**四件套，全部数据结构与算法均自行实现，未使用任何 STL 容器。

- 语言 / 标准：C++（C++17，兼容 C++11 及以后）
- 编译环境：g++ (MinGW-w64) 16.1.0 ／ MSVC（Visual Studio 18 2026，通过 CMake）
- 语言环境：源码 UTF-8，执行字符集 GBK（Windows 中文控制台正常显示中文）

## 三、代码约定

1. **不使用任何 STL 容器**：链表、哈希表、顺序栈、二叉树、菜单、输入校验全部自己编写。
2. **头文件只用允许的头文件**：`iostream`、`cstring`、`cstdlib`；此外
   - 题目五为了“建立文本文件”使用 `cstdio`（`fopen/fputs/fgets/fclose`）；
   - 题目十为了统计排序耗时使用 `ctime`（`clock()`）。
   这两个都是 ISO C 标准库，不是 C++ 的流，也不是 STL 容器，已在对应文档中说明。

3. **输入健壮**：非数字、取值越界、空输入、字段个数不对、字段过长、整行过长、输入结束（Ctrl+Z）都有明确提示并允许重新输入；任何非法输入都不会导致崩溃、数组越界或死循环。
4. **界面一致**：提示语、菜单、结果行与题目文档“项目示例”中的文字逐字一致（包括题目九的英文提示、题目十的“希尔插入排序交换次数”“归并排序比较次数”这些原话）。
5. **内存正确**：所有动态申请的内存都由对象自己释放，无泄漏、无重复释放。

## 四、构建方法

### 方式一：VS Code 任务（单个题目，g++）

打开 `Tn/Tn.cpp`，按 `Ctrl+Shift+B`（任务“C/C++: g++.exe 生成活动文件”，配置见 `.vscode/tasks.json`），生成的 exe 就在 `Tn/` 目录下。任务里的参数为：

```
D:\mingw64\bin\g++.exe -fdiagnostics-color=always -g \
    -finput-charset=UTF-8 -fexec-charset=GBK ${file} \
    -o ${fileDirname}\${fileBasenameNoExtension}.exe
```

`Tn/` 下现有的 exe 就是用它生成的（带 `-g`，所以体积偏大）。

### 方式二：命令行 g++（PowerShell，一次编译全部）

```powershell
foreach ($t in 1..10) {
    g++ -fdiagnostics-color=always -g -finput-charset=UTF-8 -fexec-charset=GBK `
        "T$t\T$t.cpp" -o "T$t\T$t.exe"
}
```

只要 `g++` 在 PATH 中即可（本机为 `D:\mingw64\bin\g++.exe`）。

## 六、项目说明文档

每题的 `Tn.docx` 都按“**需求 → 设计 → 实现 → 测试**”四部分组织，内容包括：

- 需求分析：项目简介与建设目标、功能需求表、数据需求表、非功能需求、运行环境；
